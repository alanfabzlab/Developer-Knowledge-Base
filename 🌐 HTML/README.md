**Note:**
This module is the Map of Content (MOC) for the HTML notes in this Obsidian vault. HTML is the language that creates the structure of every web page — from elements and text to links, images, attributes, styles and forms. Every example is kept minimal and executable as-is: open the file in a browser and it runs.

**Tip:**
Start at [[01 - HTML Basics]]. Learn to read the markup before you learn to style it — once you can tell the difference between structure and presentation, CSS becomes far easier.

**Prerequisite:** none. This is the first module for the web track and requires only a text editor and a modern browser.

## 🎯 Learning Path

1. **HTML Basics** → build your first pages with text, lists, links and images.
2. **Structure & Attributes** → organize files properly and label elements with `class` and `id`.
3. **Forms** → collect user input and validate it in the browser.

---

## 🎯 What You'll Be Able To Do

- Write a complete HTML5 page with `<!DOCTYPE html>`, `<head>` and `<body>`.
- Use headings, paragraphs, lists, links and images correctly.
- Label and style elements with attributes, `<style>` and CSS selectors.
- Build forms with validated inputs.

## 🎮 Practice Philosophy

A web page is readable text. If you can read the markup, you can write it. The exercises keep that principle: open the file in a browser after every tiny change. When something looks wrong, use Debug Console to inspect the element and compare the actual HTML to what you typed.
