# 🧮 Estructuras de Datos y Algoritmos (DSA)

**English:** [README.md](./README.md)

Da la bienvenida a la base de conocimiento de Estructuras de Datos y Algoritmos. Este directorio cubre conceptos fundamentales, estructuras de datos integradas en Python, resolución de problemas de forma algorítmica, análisis de complejidad y preparación para entrevistas técnicas, todo planteado con ejemplos de videojuegos (escaneos de bestiario, tablas de botín, búsqueda de rutas de NPC y emparejamiento por habilidad).

---

## 📚 Módulos Principales

1. **[01 - Introducción a las EDD](./01%20-%20Introducci%C3%B3n%20a%20Estructuras%20de%20Datos%20y%20Algoritmos.md)** — Definiciones fundamentales, importancia en la ingeniería de software, estructuras de datos integradas de Python (Listas, Diccionarios, Conjuntos) y conceptos básicos.
2. **[02 - Algoritmos y Eficiencia](./02%20-%20Algoritmos%20y%20Eficiencia.md)** — Pensamiento algorítmico, ordenamiento por inserción, rendimiento de la búsqueda lineal frente a la binaria, análisis del peor caso y optimización de rutas de mazmorra.
3. **[03 - Listas y Búsqueda Lineal](./03%20-%20Listas%20y%20B%C3%BAsqueda%20Lineal.md)** — Repaso de las listas de Python, indexación, rebanado, métodos comunes de lista, implementación del algoritmo de búsqueda lineal y análisis del rendimiento en el peor caso.
4. **[04 - Búsqueda Binaria](./04%20-%20B%C3%BAsqueda%20Binaria.md)** — Concepto de divide y vencerás, búsqueda en arreglos ordenados, implementaciones iterativa y recursiva, y manejo de casos límite.
5. **[05 - Ordenamiento por Selección](./05%20-%20Ordenamiento%20por%20Selecci%C3%B3n.md)** — Bucles anidados, construcción de una sección ordenada en el mismo espacio de memoria, intercambio de elementos mínimos y análisis de complejidad cuadrática ($O(N^2)$).
